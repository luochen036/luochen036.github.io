# BIGC_ACM Team

北京印刷学院 BIGC_ACM Team 招生与团队展示页。

网站用于介绍团队、竞赛组与项目组、代表性获奖经历、常见问题和报名联系方式，面向希望了解或加入团队的同学。

## 预览

这是一个无需构建工具的静态网页。克隆仓库后，直接在浏览器中打开 `BIGC_ACMTeam2026.html` 即可预览；也可以使用任意静态文件服务器启动本地预览：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000/BIGC_ACMTeam2026.html>。

## 技术栈

- HTML5
- CSS3
- 原生 JavaScript
- Font Awesome 图标库（通过 CDN 引入）

项目不依赖 Node.js、打包器或其他构建步骤。页面和素材放在仓库根目录，适合直接部署到 GitHub Pages 等静态托管服务。

## 目录说明

| 文件 | 说明 |
| --- | --- |
| `BIGC_ACMTeam2026.html` | 网站主页面 |
| `test.css` | 页面样式与响应式布局 |
| `logo.png`、`*.jpg` | Logo、团队照片和赛事图片等静态素材 |

修改页面时，请保持 HTML 中引用的资源文件名与实际文件名一致。新增图片前建议压缩文件体积，并为图片补充有意义的 `alt` 文本。

## 提交规范

提交信息采用 [Conventional Commits](https://www.conventionalcommits.org/zh-hans/v1.0.0/) 格式：

```text
<type>(<scope>): <subject>
```

常用类型：

| 类型 | 用途 |
| --- | --- |
| `feat` | 新增页面功能或内容 |
| `fix` | 修复页面、样式或资源问题 |
| `docs` | 修改 README、注释或其他文档 |
| `style` | 只调整格式、排版或视觉样式，不改变功能 |
| `refactor` | 重构代码，不新增功能或修复问题 |
| `test` | 新增或调整测试 |
| `chore` | 构建、依赖或仓库维护 |

示例：

```text
feat(home): 更新 2026 招生信息
fix(style): 修复移动端导航溢出
docs: 补充本地预览说明
```

提交时请遵循以下约定：

1. 一次提交只完成一个清晰的目的，避免把无关修改混在一起。
2. `subject` 使用简短、明确的动词描述改动，建议控制在 50 个字符以内，不以句号结尾。
3. 涉及背景、兼容性或迁移说明时，在标题后补充正文；关联 Issue 时在页脚写明编号。
4. 提交前确认页面能够正常打开，且资源路径、中文字符和移动端布局没有明显问题。
